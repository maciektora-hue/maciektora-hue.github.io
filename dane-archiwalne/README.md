# Dane archiwalne

Wersja 01.00 · 2026-09-19

Poczekalnia na dane, które przestały być potrzebne, ale których nie kasujemy.

## Zasada

- pliki tutaj **nie są** źródłem prawdy ani wejściem dla czegokolwiek działającego,
- przeniesienie tutaj **nie jest** usunięciem i nie kasuje historii,
- nic stąd nie znika bez świadomej decyzji poprzedzonej sprawdzeniem, że dane są kompletnie przeniesione gdzie indziej,
- aktywne źródła danych oraz pliki potrzebne WWW, SQL, skryptom lub workflowom **mają leżeć poza tym katalogiem**.

Katalog istnieje po to, żeby główna część repozytorium pokazywała stan bieżący,
a nie warstwy po zakończonych operacjach.
