# SOL błędy AI 04 — import playlist utknął mimo poprawnych danych

Data: 2026-09-11

## Stan danych

Trzy playlisty-mosty przeszły dry-run poprawnie:

- Most Głębia–Ruch: 99/99 pozycji zmapowanych;
- Most Głębia–Światło: 2/2;
- Most Światło–Ruch: 43/43.

Łącznie: 144/144 pozycji do importu poprawnie zmapowanych. Pięć źródłowych wierszy bez Spotify ID zostało pominiętych. Nie było pozycji nierozpoznanych ani niejednoznacznych.

## Co zawiodło

Nie zawiodły dane ani mapowanie. Zawiodła warstwa wykonawcza po dry-run.

Zamiast użyć jednej ustalonej drogi do wykonania COMMIT-u, SOL próbował kolejno kilku jednorazowych mechanizmów uruchomienia importera przez Render/Gunicorn. Część operacji zmiany konfiguracji została zablokowana przez warstwę narzędziową. Powstała seria obejść zamiast natychmiastowego przejścia na prostą drogę GitHub Actions → Turso.

Efekt: około 15 minut bez COMMIT-u mimo gotowych danych.

## Przyczyna organizacyjna

Brak krótkiej, kanonicznej instrukcji: użytkownik wrzuca XLSX/CSV playlisty → dry-run → GitHub Actions → Turso → weryfikacja → usunięcie workflow.

## Poprawka

Jednorazowe importy playlist z XLSX/CSV mają od teraz używać GitHub Actions z bezpośrednim połączeniem `libsql` do Turso i sekretem `TURSO_ADMIN_TOKEN`. Render/Gunicorn nie jest transportem dla tego typu importu.

Instrukcja: `SOL_INSTRUKCJA-IMPORT-PLAYLIST-XLSX-CSV.md`.
