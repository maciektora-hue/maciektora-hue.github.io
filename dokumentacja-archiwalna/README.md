# Dokumentacja archiwalna

Ten katalog przechowuje stare dokumentacje, raporty i opisy architektury zachowane wyłącznie historycznie.

## Zasada

- pliki tutaj NIE są aktualnym Source of Truth ani Source of Authority,
- nie należy używać ich jako bieżącej specyfikacji wykonawczej,
- aktualna dokumentacja znajduje się w plikach `SOL_DOKUMENTACJA-*-AKTUALNA.md` w katalogu głównym repozytorium,
- przeniesienie do tego katalogu nie oznacza usunięcia historii.

Podkatalogi zachowują pochodzenie pliku, np. `piosenki/`.
